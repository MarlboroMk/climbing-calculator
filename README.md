# 对开爬坡能力计算工具

受差速器保护限制的理论对开爬坡/加速性能计算，提供 Web 可视化界面。

参考：MS11 -1 -5 -U 对开坡性能指标论证

## 环境要求

**唯一前提：电脑上装有 Python 3.9+**

安装 Python 时请勾选 ☑ **Add Python to PATH**

下载地址：https://www.python.org/downloads/

## 使用方式

1. 将整个 `project_v1` 文件夹复制到目标电脑
2. 双击 **`启动.bat`**
3. 首次运行会自动创建虚拟环境并安装依赖（约 1~2 分钟），后续秒启动
4. 浏览器自动打开 http://localhost:8501

> 如果双击没反应，右键 `启动.bat` → 以管理员身份运行

## 功能说明

| 功能 | 说明 |
|------|------|
| 预设车型 | 内置 MS11、KUNLUN 等 53 个车型配置，一键加载车辆参数 |
| 单点计算 | 输入参数 → 计算对开起步加速度及完整中间变量 |
| Markdown 报告 | 自动生成含计算原理与公式推导的报告，支持预览和下载 |
| 热力图扫描 | 遍历前/后轴保护扭矩，生成加速度二维热力图 |
| 保存预设 | 自定义参数可保存为预设，下次直接使用 |

## 计算原理

在对开路面（一侧低附着如冰面 μ≈0.1，另一侧高附着如沥青 μ≈0.7~1.0），由于开式差速器等扭矩分配特性，低附侧首先打滑，限制了高附侧的扭矩输出。

本工具计算三种策略下的爬坡能力：

- **BTC**（制动扭矩控制）：制动低附侧车轮，间接提升高附侧扭矩
- **ELSD**（电控限滑差速器）：主动将扭矩从低附侧转移到高附侧
- **协同控制**：BTC + eLSD 同时作用

判定标准：
- 高附利用率 ≤ 100%（否则高附侧也打滑）
- 对开起步加速度 > 0.8 m/s²
